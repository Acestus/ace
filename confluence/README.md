# Confluence Drafts

This directory holds Confluence-style page drafts before they are copied,
published, or adapted into another workspace.

## Page Shape

Use this structure for new drafts:

1. Title
2. Purpose
3. Audience
4. Summary
5. Main content
6. Open questions
7. Next actions

## Notes

- Keep file names short, lowercase, and hyphenated.
- Preserve dictated fragments when a thought is incomplete.
- Mark unclear phrases in `Open questions` instead of guessing.
