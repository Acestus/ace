## Description

Build **Ace**, a private, Git-backed knowledge site for AI-generated context, implementation plans, daily journals, technical runbooks, business ideas, and reusable notes in durable Markdown.

Ace should feel more like a clean Confluence or Notion knowledge space than a graph-based second brain, while keeping ordinary files as the source of truth.

This parent ticket is the execution backlog for the first release. The subtasks below break the work into agent-ready packages with clear boundaries, dependencies, and acceptance criteria.
