## Description

Build **Journal**, a private Markdown-first knowledge website that publishes Hugo content through Azure Static Web Apps, authenticates the owner with Microsoft Entra ID, uses .NET 10 Azure Functions for optional dynamic APIs, stores large assets in Azure Blob Storage, renders PlantUML diagrams during CI, and records backend telemetry in Application Insights.

This is the parent implementation ticket. The 14 child issues below map to the numbered work packages in the attached plan and should be used as the execution backlog for the project.

## Planned work packages

* Repository scaffold
* Hugo content model and archetypes
* Confluence-style Hugo theme
* Technical-documentation writer specification
* PlantUML build integration
* Bun and vanilla TypeScript pipeline
* Chart.js integration
* .NET 10 Azure Functions baseline
* Storage and managed identity integration
* Azure infrastructure
* Static Web Apps authentication
* Application Insights observability
* GitHub Actions deployment
* Sample content and operating guide
